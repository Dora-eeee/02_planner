# 📚 Smart Campus Planner

**저와 같은 대학원생을 위한 일정 관리 웹앱**입니다.
수업, 프로젝트, 논문, 개인 할 일을 한 곳에서 관리할 수 있도록 만들었습니다.
회원가입이나 설치 없이, 브라우저에서 바로 열어서 사용할 수 있습니다.

---

## 🎯 프로젝트 소개

대학원생은 수업/과제, 연구 프로젝트, 논문 준비, 개인적인 일정까지 서로 다른 성격의 할 일을 한꺼번에 관리해야 합니다.
**Smart Campus Planner**는 이런 할 일들을 **하나의 화면**에서 카테고리별로 구분하고, 중요도와 마감일에 따라
한눈에 정리할 수 있도록 도와주는 간단한 To-Do 웹앱입니다.

## 💡 만든 목적

- 수업, 프로젝트, 논문, 개인 할 일이 여러 앱(캘린더, 메모, 메신저 등)에 흩어져 있어 놓치기 쉬운 문제를 해결하기 위해 만들었습니다.

- 카테고리와 중요도를 함께 표시해서, "지금 무엇을 먼저 해야 하는지" 쉽게 판단할 수 있도록 하는 것이 목표입니다.
- 로그인이나 서버 없이도, 브라우저를 새로고침하거나 다시 열어도 입력한 내용이 사라지지 않도록 만들었습니다.

> 프로젝트의 상세한 목적, 대상 사용자, 요구사항은 [`PRD.md`](./PRD.md) 문서에 정리되어 있습니다.

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| ✅ 할 일 추가 | 제목, 카테고리, 중요도, 마감일을 입력해서 새로운 할 일을 등록할 수 있어요 |
| 🏷️ 카테고리 설정 | 할 일을 **수업 / 프로젝트 / 논문 / 개인** 중 하나로 분류할 수 있어요 |
| ⭐ 중요도 설정 | 할 일의 중요도를 **상 / 중 / 하**로 지정할 수 있어요 |
| 📅 마감일 지정 | 할 일마다 마감일(날짜)을 정할 수 있어요 (오늘 이전 날짜는 선택할 수 없어요) |

| ☑️ 완료 체크 | 체크박스를 눌러 완료/미완료 상태를 바꿀 수 있어요 (완료된 항목은 취소선으로 표시) |
| 🗑️ 할 일 삭제 | 필요 없어진 할 일은 삭제 버튼으로 목록에서 지울 수 있어요 |
| 📊 전체 완료율 표시 | 전체 할 일 중 몇 %를 완료했는지 숫자와 막대그래프로 확인할 수 있어요 |
| 🔃 자동 정렬 | 할 일 목록이 **마감일이 빠른 순 → 중요도(상 > 중 > 하) → 입력한 순서**로 자동 정렬돼요 |
| 💾 새로고침해도 유지 | 브라우저를 새로고침하거나 다시 열어도 입력한 할 일이 그대로 남아있어요 (브라우저 저장 기능 사용) |

## 🖱️ 사용 방법

1. `index.html` 파일을 더블클릭하거나, 웹 브라우저(크롬, 엣지 등)로 엽니다. (별도 설치나 서버 실행이 필요 없습니다.)
2. **"새 할 일 추가"** 영역에서 제목을 입력하고, 카테고리 / 중요도 / 마감일을 선택한 뒤 **"+ 할 일 추가"** 버튼을 누릅니다.
3. 아래 **"할 일 목록"** 영역에 새로 추가한 항목이 나타납니다. 마감일과 중요도에 따라 자동으로 순서가 정렬됩니다.
4. 할 일을 끝냈다면 항목 왼쪽의 **체크박스**를 눌러 완료 표시를 합니다.
5. 더 이상 필요 없는 할 일은 항목 오른쪽의 **"삭제"** 버튼으로 지울 수 있습니다.
6. 목록 위쪽의 **완료율**을 보면서 오늘/이번 주 할 일을 얼마나 처리했는지 확인할 수 있습니다.
7. 브라우저를 껐다가 다시 열거나 새로고침해도, 입력했던 할 일은 그대로 남아있습니다.

## 🛠️ 사용한 기술

이 프로젝트는 별도의 설치나 프레임워크 없이, 브라우저에서 바로 실행되는 **정적 웹페이지**로 만들어졌습니다.

- **HTML5** — 화면 구조 (입력 폼, 할 일 목록 등)
- **CSS3** — 디자인 및 레이아웃 (색상, 글꼴, 반응형 배치)
- **JavaScript (Vanilla JS)** — 할 일 추가/완료/삭제, 완료율 계산, 정렬 등 모든 동작 로직
- **Web Storage API (`localStorage`)** — 브라우저에 할 일 데이터를 저장해서 새로고침해도 유지되도록 처리
- **Google Fonts** (`Poppins`, `Pretendard`) — 모던한 타이틀과 가독성 좋은 본문 글꼴


> 별도의 서버, 데이터베이스, 빌드 도구(Node.js 등) 없이 브라우저만 있으면 바로 실행할 수 있습니다.

## 📁 프로젝트 파일 구성

```
02_planner/
├── index.html      # 화면 구조 (할 일 입력 폼, 목록, 완료율 영역)
├── style.css       # 디자인 스타일 (색상, 폰트, 레이아웃)
├── script.js       # 기능 동작 로직 (추가/완료/삭제/정렬/저장)
├── PRD.md          # 프로젝트 기획 문서 (목적, 대상 사용자, 요구사항, MVP 범위)
├── TASKS.md        # 단계별 개발 작업 계획 (3단계로 나눈 구현 순서)
├── PROMPTS.md      # 각 단계를 구현할 때 사용한 AI 요청 프롬프트 모음
└── README.md       # 지금 보고 있는 프로젝트 소개 문서
```

| 파일 | 역할 |
|------|------|
| `index.html` | 웹페이지의 뼈대가 되는 파일로, 브라우저에서 이 파일을 열면 앱이 실행됩니다 |
| `style.css` | 화면의 색상, 글꼴, 배치 등 디자인을 담당합니다 |
| `script.js` | 버튼 클릭, 할 일 추가/완료/삭제, 데이터 저장 등 실제 동작을 담당합니다 |
| `PRD.md` | 이 프로젝트를 왜, 누구를 위해, 어떤 기능으로 만들었는지 정리한 기획 문서입니다 |
| `TASKS.md` | 전체 기능을 3단계로 나누어 구현한 작업 계획 문서입니다 |
| `PROMPTS.md` | 각 단계를 AI에게 구현 요청할 때 사용한 프롬프트 모음입니다 |
